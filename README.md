This excel sheet needs to be a macro enabled workbook. 

Configure your aircraft on the "Aircraft" tab. Add a new row for each aircraft. 

Use the "Flights" tab to add data for each flight. Click the ADD FLIGHT button to add a new row. Make sure to enter an Aircraft ID from one of the aircraft you configured earlier. 

Data on the "Totals", "Currencies", and "FAA 8710" tabs will update when you cycle between those pages.
